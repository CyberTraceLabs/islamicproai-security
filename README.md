# IslamicProAI — Security Audit

This repository contains the official security audit conducted by **CyberTrace Labs BD** for IslamicProAI.

## What is done here?

We perform full security testing for IslamicProAI before public launch:

- Penetration testing
- Vulnerability assessment
- Bug bounty simulation
- Remediation verification

All findings are documented as separate reports in this repository.

## About IslamicProAI

IslamicProAI is Bangladesh's first Halal AI + E-commerce platform, built by Hussain Ahmed Toushin. It handles user data, payments, and AI queries — security is critical.

## Audit Scope

- Web application (noormarket.ai)
- API endpoints
- Authentication system
- Payment flow

## Reports

Each vulnerability is documented in a separate file in the `/reports` folder.

Example:
- `XSS-001.md`
- `IDOR-002.md`
